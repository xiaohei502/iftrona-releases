# 伊芙特罗娜的旧日见闻 1.5 · 快照版

- 发布日期：2026-11-13
- [下载与版本页面](https://github.com/xiaohei502/iftrona-releases/releases/tag/v1.5)
- [游戏官网](https://iftrona-old-tales.garvillezxo303.chatgpt.site/)
- [保留的 1.4 稳定版](https://github.com/xiaohei502/iftrona-releases/releases/tag/v1.4)

本次更新重点完善开篇的画面演出、声音编排与阅读体验。本版面向尝鲜与反馈，内容较多、仍有已知问题。Android 已完成用户手机试玩并获认可；这不代表全部内容已通过最终复核，希望更稳妥的玩家可继续使用 1.4 稳定版。

## 画面与故事呈现

- 更新前七章的场景、人物立绘和部分关键 CG，调整人物的大小、站位、朝向及场景衔接。
- 第八章可显示已有场景背景；尚未完成画面的后续章节继续以文字方式阅读。
- 优化人物资料页的查找与分类，支持立绘切换、点击放大和全屏查看；资料随阅读进度逐步展开。

## 声音与阅读体验

- 配乐、环境声和音效的新编排扩展到第49章，音乐馆现收录96首曲目。
- 补充界面操作的声音反馈，新增场景转场、加载动画、首次启动信笺、章末旅程书签及资料解锁提示，让阅读衔接更流畅。
- 新存档显示保存时的画面；旧存档继续使用章节封面作为预览。
- 优化文字模式的氛围背景、章节标题和中文换行。
- 提供沉浸听音模式，听音进度与普通阅读分开保存。
- Android 增加后台音乐播放：切换应用、锁屏及游戏内确认退出后可继续听音乐，通过通知栏暂停或停止。系统“强行停止”不在继续播放范围内。
- 读取存档后，自动播放和快进回到关闭；“仅跳过已读”默认开启。

## 彩蛋

在“设置 → 系统”底部加入《雪夜守火》《暴食の伊芙》，成绩单独记录，不影响阅读存档。

## 安装与兼容

- Windows：完整解压 ZIP，再运行其中的 EXE；EXE 与 PCK 必须放在同一个文件夹。
- Android：面向64位 ARM 设备，使用 APK 覆盖安装。请勿先卸载旧版，以免丢失本地存档。
- 更新前建议备份重要存档；本次不要求清空阅读进度。

## 已知问题与持续制作范围

- 后续章节美术、人物资料及部分关键动作和特效仍在逐章完善，不代表全篇画面已完成。
- 声音已接入的章节不等于全部完成主观试听，少量旧配音缺漏与对应问题仍待修订。
- 第49章存在原文与阅读文本分段差异、两句缺配音及一句配音文本不一致的问题，本次保持既有内容。
- 部分音乐使用通用封面，后续会继续补齐。
- 部分存档的章节进度百分比显示不准确，已检查的保存位置和读档恢复正常。
- 人物资料的部分校验尚未收口，本版不代表全部资料已完成最终复核。
