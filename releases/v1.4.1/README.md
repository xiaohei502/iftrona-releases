# 1.4.1 快照版

这一版更新第一章的舞台表现与阅读体验，优化章节阅读模式与章末衔接。

- 完善章节的文字阅读兼容性，保留正文、配音和音乐体验。
- 选章、继续阅读、旧存档读取、日志回看和自动接续保持可用。
- 完善顺序接续与阅读模式恢复，保留原有阅读偏好。
- 优化第一章尾声 CG 与结算界面的衔接。
- 修复一处章节导入缓存异常，避免顺序阅读时跳过第四章。
- 其他章节沿用已有开放策略，其文本与配音收录范围不代表完整视觉演出已制作完成。

这是面向尝鲜与反馈的预发行快照，1.4 正式版继续保留下载。

## 安装

- Windows：完整解压 ZIP，保持 EXE 与 PCK 在同一个文件夹，再运行 EXE。
- Android：使用系统安装器安装；沿用 1.4 的包名和签名，版本号为 1.4.1、versionCode 为 8。具体机型兼容性尚未完成真机验证。
- 更新前建议备份存档；不要卸载旧版来清除数据。已有存档保留，可继续读取。

完整 SHA-256 见随附的 `SHA256SUMS.txt`，下载后可核对文件完整性。
